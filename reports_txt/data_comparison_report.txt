- **Final Features**: 26
- **Method**: 
    1. Removed High Correlation features (>0.98).
    2. Random Forest Feature Importance (Top 25 selected).

## 4. Data Transformation
- **Normalization**: All features have been scaled using `StandardScaler` (Mean=0, Variance=1).
- **Format**: Converted to numerical float32/float64.
- **Leakage Prevention**: Scaling and SMOTE were applied **only** to the training split to ensure the test set remains a truly independent evaluation set.
